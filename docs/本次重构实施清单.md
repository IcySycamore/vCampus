## 三、验收标准

- 右上角点用户名 → 弹窗显示 登录名/身份/标识/姓名（管理员显示登录名）；可改密、可退出登录
- 侧栏：学生/教师**看不到**「用户管理」；管理员可见并能完成 单个/批量(文件)/启停/编辑/注销
- 批量导入 1000 条：分 20 包发送、显示进度、服务端每次只写一次文件（总落盘 20 次而非 1000 次）
- 杀掉服务端进程 → 客户端 15s 内回到登录页并提示「连接已断开，请重新登录」，**不再卡住**
- 心跳 ACK 携带时间戳；界面显示的服务器时间与客户端时钟偏差稳定（RTT 抖动内）
- `mvn -B clean test` 全绿；新增横切件（`AccountPopupPanel`、`ClientClockSync`、`saveAll`）各有单测
